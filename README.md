# 餐饮经营分析系统 · 收入分析模块 demo

把课程 Excel《利润桥及毛利率分析》里的收入分析，做成打开浏览器就能用的看板：渠道 → 同店新店 → 门店 → 品类量价 → 客流客单，五层下钻，每层自动给出一句话结论。

开发方式：老板在飞书里下指令，DeepSeek Harness（DSH）里的 AI 团队（产品 / 数据 / 前端 / 测试）分工干活，过程记录在 `openspec/`，代码存 GitHub。角色规则见 [AGENTS.md](AGENTS.md)。

## 目录

| 路径 | 内容 | 负责角色 |
|---|---|---|
| `openspec/changes/` | 每个功能的需求、设计、任务清单 | 产品 |
| `data/revenue_2025-09.json` | 演示输入数据（来自课程 Excel） | 数据 |
| `data/golden_expected.json` | 验收基准：Excel 原公式重算的结果 | 只读 |
| `src/engine/` | 计算引擎 | 数据 |
| `src/web/`、`index.html` | 看板页面 | 前端 |
| `tests/` | 自动测试 | 测试 |

## 7 天节奏

| 天 | 目标 | 你在飞书里发什么 |
|---|---|---|
| D1 | 环境：飞书机器人、GitHub 仓库、DSH 团队插件 | `/status` 确认机器人在线 |
| D2 | 需求确认 | `读一下 openspec/changes/add-revenue-analysis-dashboard，用三句话告诉我要做什么` |
| D3 | 计算引擎 | `用智能体团队开工：数据角色做 tasks 第 1 组，测试角色同时做第 2 组，按 AGENTS.md 规则` |
| D4 | 看板页面 | `前端角色做 tasks 第 3 组，完成后截图发我` |
| D5 | 联调修复 | `跑 npm test，把没通过的项列给我，分派给对应角色修` |
| D6 | 验收 | `测试角色出验收报告；全部通过就开 PR` |
| D7 | 彩排、归档 | `归档这次变更，用一句话汇报结果` |

## 本地预览

需要 Node.js 24 及以上版本。

```sh
npm test    # 跑测试
npm start   # 打开 http://localhost:8080
```

## 数据说明

全部为课程演示用模拟数据，不是真实经营数据。同店口径下的渠道和品类数据，是按同店收入占比（85.7%）折算的，与课程 Excel 的口径一致。
