# analysis-report Specification

## Purpose
把收入分析五层结果按月度经营分析汇报的顺序整理成一份报告，用户在浏览器里查看后可以直接打印或另存为 PDF，替代每月手工截图做 PPT。

## Requirements

### Requirement: 报告结构
系统 SHALL 提供分析报告页，按以下顺序组织内容：封面信息（标题、数据来源、分析期间、生成时间）→ 收入总览指标 → 渠道结构 → 同店 / 新店 → 门店排名 → 品类量价 → 客流客单 → 结论汇总。每个分析章节包含该层一句话结论、一张主图和关键明细表。

#### Scenario: 打开报告
- **WHEN** 用户从看板导航点击"分析报告"
- **THEN** 报告页按上述 8 个部分依次展示，章节标题与看板五层名称一致

#### Scenario: 结论汇总
- **WHEN** 用户查看报告末尾的"结论汇总"
- **THEN** 依次列出五层的一句话结论，文字与看板各层顶部结论完全一致

### Requirement: 报告数据一致性
报告中的所有数值和结论 SHALL 来自当前数据集的同一次分析结果，与看板显示一致；当前数据集切换后，报告随之更新。

#### Scenario: 导入数据后的报告
- **WHEN** 用户导入新数据后打开报告
- **THEN** 封面显示导入文件名和期间，报告中的本期收入、同比差额与看板指标卡一致

#### Scenario: 演示数据报告
- **WHEN** 当前数据集为演示数据
- **THEN** 报告首页指标与 `data/golden_expected.json` 中对应值偏差 <= 0.01，封面注明"演示数据"

### Requirement: 口径与单位标注
报告 SHALL 在对应章节注明金额单位（万元）、门店客流客单表由元换算为万元，以及同店渠道 / 品类数据为按同店收入占比折算的演示口径（当数据为折算时）。

#### Scenario: 折算口径提示
- **WHEN** 当前数据集的同店销量为系统折算
- **THEN** 品类量价和客流客单章节显示"同店口径为按同店收入占比折算"的注释

### Requirement: 打印与导出 PDF
报告页 SHALL 提供"打印 / 导出 PDF"按钮，调用浏览器打印；打印版式为 A4 纵向，隐藏导航和按钮，每个分析章节从新页开始，图表与表格不被分页截断。

#### Scenario: 导出 PDF
- **WHEN** 用户点击"打印 / 导出 PDF"并选择"另存为 PDF"
- **THEN** 得到的 PDF 不含导航栏和按钮，每个章节标题位于页首，图表完整可见

#### Scenario: 图表库未加载
- **WHEN** 图表库加载失败
- **THEN** 报告仍显示结论和明细表，图表位置显示"图表未加载"提示，打印不报错
